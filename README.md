## Enfoque de trabajo

### Entender el contexto
Antes de lanzar herramientas, analizo alcance, superficie expuesta, criticidad y objetivo del test.

### Enumerar con criterio
La enumeración no es acumulación de datos. Es reducción de incertidumbre.

### Validar manualmente
La automatización acelera. El análisis humano confirma explotación, impacto y relevancia.

### Priorizar por riesgo real
No todos los hallazgos pesan igual. Priorizo exposición, probabilidad de abuso y consecuencias.

### Reportar para decisión
Un buen informe no solo describe el fallo. Permite corregirlo.
